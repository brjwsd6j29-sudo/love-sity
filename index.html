📌 Как поменять музыку для ВСЕХ:

1
Открой свой репозиторий на github.com
2
Нажми Add file → Upload files
3
Перетащи новый mp3-файл и назови его music.mp3
4
Нажми Commit changes — согласись заменить старый файл
5
Через 1–2 минуты музыка заиграет у всех посетителей 🎉
